================================================
BUILD TECHNOLOGY
================================================

TwoHearts V1 is implemented as a:

MOBILE-FIRST WEB APPLICATION
+
CAPACITOR NATIVE RUNTIME
+
ANDROID APK BUILD THROUGH GITHUB ACTIONS

The web technology is the implementation layer.

Capacitor provides the native Android bridge where native
device capabilities are required.

IMPORTANT:
TwoHearts must NOT be designed or implemented as a generic
website that happens to be placed inside a WebView.

The application should visually and behaviorally feel like a
purpose-built mobile application.

The fact that Capacitor uses a WebView internally must not
translate into a "website inside an app" appearance.

dependencies merely because Capacitor is being used.

CANVA SLIDE 36.

The supplied CANVA SLIDE NUMBER determines WHERE.

Never infer the requested screen from a number alone.
