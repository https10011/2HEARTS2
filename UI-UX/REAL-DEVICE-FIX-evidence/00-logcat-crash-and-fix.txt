================================================================
4. INTERPRETATION
================================================================

The exception is thrown from a coroutine worker (`CoroutineScheduler`), not the
main thread directly, which is why the app is reported as an immediate
"has stopped" rather than a visible error screen: `AppStateService.initialize()`
runs in a `LaunchedEffect` coroutine, and an uncaught exception there reaches the
default uncaught-exception handler and terminates the process.

This is consistent with the reported symptom: install succeeds, launch crashes.
